# CCC Core

## Syfte

CCC Core är den stabila grundplattformen som alla framtida CCC-moduler bygger ovanpå.

Container13 används som första verkliga referensimplementation.

---

# Core Components

## Identity Core
- användare
- företag
- roller
- behörigheter

Grund:
- Firebase Authentication

## Database Core
- datamodell
- verksamhetsdata
- relationer

Grund:
- Firestore

## Storage Core
- filer
- bilder
- dokument

Grund:
- Firebase Storage

## Security Core
- åtkomstkontroll
- regler
- dataskydd

Grund:
- Firebase Rules

## Configuration Core
- inställningar
- anpassningar
- modulkonfiguration

Grund:
- settings-struktur

## Versioning Core
- versionshantering
- historik
- förändringar

Grund:
- VERSION.txt
- changelog
