# CCC Core Map

## Syfte

Denna fil beskriver vilka delar av den beprövade Container13-plattformen
som kan utvecklas till generella CCC-moduler.

Container13 fungerar som en verkligt testad referensimplementation.
Målet är att återanvända fungerande byggblock och generalisera dem till
en bredare verksamhetsplattform.

------------------------------------------------------------------------

-   Grundläggande användarbehörighet

# Grundprincip

CCC ska inte byggas från noll.

CCC bygger vidare på beprövade lösningar från verklig användning.

Container13 är första testmiljön.

Målet är att omvandla fungerande delar till återanvändbara
verksamhetsmoduler.
