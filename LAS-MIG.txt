sw.js

admin/sw.js
VERSION.txt

Viktigt efter uppladdning:
1. Vänta tills GitHub Pages har publicerat ändringen.
2. Stäng C13 Admin helt och öppna den igen.
3. Om den gamla versionen fortfarande visas, uppdatera sidan med Ctrl + F5.
4. Det lilla paketet kan inte ta bort gamla filer från GitHub. Den kompletta versionen är därför bäst för hela städningen.
