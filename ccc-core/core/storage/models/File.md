# File Model

## Syfte

Representerar en fysisk fil som lagras i CCC.

## Information

Kan innehålla:

- filnamn
- filtyp
- storlek
- sökväg
- skapad datum
- ägare

## Relationer

En Resource kan bestå av en eller flera Files.

## Referens från Container13

- uppladdade bilder
- Firebase Storage-filer
