CCC v2.4.1 – modulstruktur

Utvecklingsregel:
- En modul = en mapp under /ccc-core.
- HTML, CSS och JS som hör till modulen ligger tillsammans.
- /ccc-core/auth = inloggning + registrering + auth-filer.
- /ccc-core/dashboard = dashboard + CSS/JS.
- /ccc-core/vision = CCC Vision + CSS/JS/demo.
- /ccc-core/version.js = gemensamt versionsnummer.
- /ccc-core/demo-ui behålls tills vidare för gamla/testlänkar och kompatibilitet.

Ingen ny /ccc-mapp i roten.
