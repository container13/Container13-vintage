# Lina – Broker Gate

Status: PLANERAD. Ingen mäklare är vald.

Syfte: innan riktig handel ska Lina jämföra kandidater på exakt samma frysta affärer och realistiska kostnader.

Kandidater att utvärdera:
- Interactive Brokers (IBKR)
- Alpaca
- Nordnet

Avanza kan följas som svensk referens, men är inte huvudspår för egen robotintegration i nuläget.

Broker Gate ska jämföra:
- officiellt API och stabil orderläggning
- paper trading
- amerikanska aktier
- courtage
- spread/slippage
- valutaväxling SEK/USD
- kontoform, svensk skatt och ISK-frågan
- ordertyper
- säker nyckelhantering
- drift/uptime
- möjlighet att stänga av handel centralt

Kostnadstest:
G2 ska köras utan parameterändringar genom flera friktionsnivåer och, när mäklare väljs, genom den mäklarens verkliga kostnadsmodell.

Ingen mäklare får väljas enbart för att den ger bäst historiskt G2-resultat. Teknik, säkerhet, skatt och faktisk tillgänglighet vägs in.

Handel förblir AV tills separat beslut tas.
