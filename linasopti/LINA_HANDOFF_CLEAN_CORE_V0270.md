# Lina Clean Core V0.2.70 handoff

Bas: V0.2.69, där Gen4 research är 4/4 FROZEN · GITHUB ✓ och exakt en familj kvalificerar.

V0.2.70 lägger endast till kandidatsteget efter fryst GitHub-verifierad sammanställning. Kandidat väljs deterministiskt bland familjer som klarar alla låsta gates, sorterat på samma låsta riskjusterade score; P/L är inte primärt. Kandidaten fryses lokalt före async evidenssynk. Ingen Gen4-research körs, ingen rerun/rescue, Forward öppnas inte och Handel är AV.

UI: knappen `Välj enligt låst regel + frys kandidat` visas först när sammanställningen är GitHub-verifierad. Recovery-starttext: `Inget nytt att spara eller återställa.`

Nästa större steg efter GitHub-verifierad kandidat: Generation Engine.
