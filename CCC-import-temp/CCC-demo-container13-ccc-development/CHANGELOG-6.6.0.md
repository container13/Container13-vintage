# Container13 Vintage 6.6.0

## Startanimation som egen dashboardflik

- Fyra val:
  1. Klassisk stjärnöppning
  2. Krympande guldstjärna + stjärnöppning
  3. Stjärnöppning med bakgrundsbild
  4. Ingen animation
- Bakgrundsbilder komprimeras automatiskt före uppladdning.
- Bilden kan fylla skärmen eller visas i sin helhet.
- Reservfärgen används om bilden inte hinner eller kan laddas.
- Bild, färger och tider kan förhandsgranskas före aktivering.
- Aktivt alternativ och osparade ändringar visas separat.
- Vanliga Inställningar innehåller bara ett enkelt val och en genväg till Startanimation.
