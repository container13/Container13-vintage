# Resource Model

## Syfte

Representerar en digital resurs i CCC.

## Ansvar

Hanterar:

- bilder
- dokument
- filer
- metadata
- relation till verksamhetens innehåll

## Exempel

- produktbild
- galleriobjekt
- marknadsföringsmaterial
