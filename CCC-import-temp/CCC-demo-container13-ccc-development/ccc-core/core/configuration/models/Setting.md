# Setting Model

## Syfte

Representerar en enskild inställning i CCC.

## Exempel

- openingHours
- theme
- animation
- statusBar

## Struktur

En setting innehåller:

- namn
- värde
- typ
- tillhörande modul

## Referens från Container13

- Firestore settings
- öppettider
- temaval
