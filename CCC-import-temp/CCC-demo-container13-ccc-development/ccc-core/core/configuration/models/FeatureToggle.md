# Feature Toggle Model

## Syfte

Hanterar funktioner som kan aktiveras eller avaktiveras.

## Exempel

```
galleryEnabled = true

animationEnabled = false

reviewsEnabled = true
```

## Användning

Gör det möjligt att anpassa CCC efter olika verksamheters behov.

## Referens från Container13

- funktionsväxlar
- adminval
