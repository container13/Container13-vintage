# Feature Toggle Service

## Syfte

Hanterar aktivering och avaktivering av CCC-funktioner.

## Ansvar

- kontrollera aktiva funktioner
- styra modulers tillgänglighet
- möjliggöra anpassning per företag

## Exempel

- galleryEnabled
- animationEnabled
- reviewsEnabled

## Status

Planerad CCC Configuration Service.
