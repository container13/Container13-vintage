# Configuration Data Map

## Container13 till CCC

Befintliga Container13-inställningar:

- öppettider
- tema
- animation
- statusrad
- funktionsväxlar

Mappas till CCC:

- Configuration
- Setting
- FeatureToggle

## Princip

CCC ska inte vara beroende av Container13-specifika namn.
Modellen ska kunna återanvändas av andra verksamheter.
