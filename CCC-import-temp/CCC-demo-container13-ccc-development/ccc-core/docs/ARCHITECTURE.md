# CCC Core Architecture

## Syfte

Beskriver den interna strukturen för CCC Core.

CCC Core är den gemensamma plattformen som framtida moduler bygger ovanpå.

## Lager

- Core: grundfunktioner
- Modules: verksamhetsfunktioner
- Services: gemensamma tjänster

## Princip

Tydlig separation mellan plattform och applikation.
