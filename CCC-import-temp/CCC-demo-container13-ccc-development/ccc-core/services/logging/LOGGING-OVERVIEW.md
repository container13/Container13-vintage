# Logging Service Overview

## Syfte

Logging Service ger CCC spårbarhet och historik.

## Arkitektur

Event

↓

Logging Service

↓

Storage Adapter

↓

Log History

## Användning

Ger svar på:

- vem gjorde vad?
- när hände det?
- vad ändrades?

## Container13 Connection

Container13 har grunden:

- analytics_events
- adminaktiviteter

CCC utvecklar detta till ett gemensamt loggsystem.
