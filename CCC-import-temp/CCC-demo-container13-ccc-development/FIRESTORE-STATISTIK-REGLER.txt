CONTAINER13 – FIRESTORE-REGLER FÖR BESÖKSSTATISTIK

Version 6.3 behöver två nya samlingar:
- analytics_visitors
- analytics_days

Lägg in följande match-regler INUTI din befintliga:
match /databases/{database}/documents { ... }

  match /analytics_visitors/{visitorId} {
    allow create, update: if request.auth == null
      && request.resource.data.keys().hasOnly([
        "lastSeenAt", "lastPage", "deviceType", "platform",
        "installedPwa", "visitCount"
      ]);
    allow read: if request.auth != null;
    allow delete: if false;
  }

  match /analytics_days/{dateId} {
    allow create, update: if request.auth == null
      && request.resource.data.keys().hasOnly([
        "date", "updatedAt", "pageViews", "uniqueVisitors", "pages"
      ]);
    allow read: if request.auth != null;
    allow delete: if false;
  }

VIKTIGT
- Ersätt inte dina nuvarande regler. Lägg bara till blocken ovan.
- Adminpanelen måste vara inloggad för att läsa statistiken.
- Statistiken lagrar inga namn, e-postadresser eller exakta positioner.
- En unik besökare motsvarar en webbläsare/enhet och är därför en uppskattning.
