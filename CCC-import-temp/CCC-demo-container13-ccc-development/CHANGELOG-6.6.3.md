# Container13 Vintage 6.6.3

## Tidsjustering i förhandsvisningen

- Krymptid eller väntetid kan ändras direkt på testsidan.
- Stjärnöppningens tid kan ändras direkt på testsidan.
- **Kör testet igen** använder de angivna tiderna.
- **Återställ tider** återgår till tiderna från adminpanelen.
- Retur kan användas för att snabbt köra om testet.

Ändringarna är endast testvärden. De sparas inte och aktiveras inte på hemsidan.
