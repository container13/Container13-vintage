CONTAINER13 – OM OSS 6.10.1

Detta paket innehåller hela Om oss-funktionen och rättningen som gör
att menylänken verkligen döljs när Om oss stängs av i adminpanelen.

LADDA UPP TILL GITHUB

1. Öppna repositoryt Container13-vintage på GitHub.
2. Välj Add file > Upload files.
3. Dra in INNEHÅLLET i mappen Container13-vintage-om-oss-6.10.1.
4. Behåll samma mappstruktur och ersätt befintliga filer.
5. Filen omoss.html ska ligga i roten bredvid index.html.
6. Spara ändringen och vänta tills GitHub Pages är färdig.
7. Uppdatera hemsidan med Ctrl + F5.

Admininställningen är redan sparad i Firestore. Om Om oss är inställd
som dold behöver du därför inte dölja sidan på nytt efter uppladdningen.
