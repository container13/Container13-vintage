# Starta eget

Status: UTFORSKAS

Detta är första testet av den lätta projektmodellen för ett icke-kodprojekt.

## Syfte
Undersöka om Magnus kan bygga en hållbar sidoverksamhet kring AI-stödd produkt-/apputveckling och andra befintliga uppdrag, utan att skapa onödig administration eller riskera nuvarande anställning.

## Arbetssätt
- Läs CURRENT_STATE.json och HANDOFF_CURRENT.md när arbetet återupptas.
- Fånga nya idéer i IDEBANK.md utan att automatiskt byta fokus.
- Verifierade beslut/fakta förs till DECISIONS.md.
- Ekonomi, skatt, juridik och arbetsgivarfrågor ska verifieras mot aktuella primärkällor innan de behandlas som fakta.
- Använd repositoryts solutions/ när ett tidigare löst arbetssätt är relevant.
- Håll modellen lätt: inga release-gates, versionsnummer eller CI förrän projektet faktiskt innehåller programvara som behöver dem.

## Mål för första fasen
Inte att säga upp sig eller skala snabbt. Målet är att avgöra om verksamheten kan få en första riktig extern betalande kund och samtidigt skapa en bra struktur för befintliga sidouppdrag.
