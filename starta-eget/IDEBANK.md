# Idébank

Fånga snabbt. En idé här betyder inte att den ska byggas nu.

## AI / digitalisering
- Erbjuda små företag hjälp från verksamhetsproblem -> prototyp -> test -> fungerande lösning.
- Använda befintliga egna projekt som portfolio/case där det är lämpligt.
- Första externa betalande kunden som viktigaste validering, snarare än många kunder direkt.

## Projektmall
- Ge bort en lätt projektmall på GitHub för personer som bygger med AI men inte är traditionella utvecklare.
- Budskap: behåll kontrollen när projektet växer och slipp bygga samma sak flera gånger.
- Möjlig långsiktig riktning: ett enkelt operativsystem/arbetssätt för AI-utveckling för vanliga människor.
- Låt verklig användning i egna projekt avgöra vad mallen behöver innan eventuell större produkt byggs.

## Övriga verksamhetsspår
- Snickeriarbete.
- Mark/grävrelaterade uppdrag.
- Undersöka om dessa och digitalisering lämpligen kan ligga under samma framtida AB.
