# Remember appikon — vald design 6

2026-10-21. Release 0.1.149. Projektägaren valde förslag nr 6: svepande handskrivet cremevitt R på skogsgrönt.

Bildgenerering användes för att isolera det valda motivet till en kvadrat med heltäckande bakgrund. Instruktion: bevara formen från övre högra nr 6 på jämförelsebilden, ta bort nummer/omgivning, fyll hörn med grönt; inga nya symboler. ImageMagick användes endast för export till opaka PNG i rätt pixelstorlekar. 512px-filen är projektets rasteroriginal för denna release; ingen nygenerering behövs för kommande storleksexporter.

- 180px: apple-touch-icon för iPhone.
- 192px och 512px: manifestets purpose:any. Inga förbakade rundade hörn; operativsystemet formar ikonen.
- Version i filnamnet undviker återanvändning av en gammal resursadress. Befintliga installerade iPhone-genvägar kan behålla sin gamla ikon; faktisk uppdatering på enheten är inte verifierad.
- Alla nio releaseingångar länkar till samma manifest/ikoner. Appnamn, start_url, scope och display har inte ändrats. Inga andra projekts ikoner har berörts.
