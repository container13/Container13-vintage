================================================== VIKTIGASTE REGELN
==================================================

Mycket snack och lite verkstad vill vi inte ha.

-   Prioritera att lösa uppgiften framför långa förklaringar.
-   Undvik upprepningar.
-   Beskriv planen kort och genomför sedan arbetet.
-   Resonera bara så mycket som behövs för att fatta rätt beslut.
-   Leverera resultat.

================================================== SYFTE
==================================================

Denna fil är ChatGPT:s arbetsmanual för CCC. Den ska påminna ChatGPT om
projektets arbetssätt och tidigare beslut så att användaren inte behöver
upprepa dem. Vid konflikt mellan denna fil och användarens aktuella
instruktion gäller alltid användarens aktuella instruktion.

================================================== LEVERANSKONTROLL
==================================================

En leverans är inte klar förrän innehållet är kontrollerat.

Kontrollera alltid att: - Det som utlovats faktiskt finns med. - Alla
ändrade filer finns i ZIP:en “Endast ändrade filer”. - Komplett ZIP
innehåller samma ändringar. - Filstruktur och sökvägar är korrekta. -
Versionsnummer och cachebrytning är uppdaterade när det behövs.

Kontrollera först. Leverera sedan.

================================================== LEVERANSSTANDARD
==================================================

Vid varje leverans ska normalt två ZIP-filer skapas:

1.  Komplett projekt.
2.  Endast ändrade filer.

ZIP med ändrade filer ska: - Spegla projektets mappstruktur. - Innehålla
samtliga ändrade filer. - Innehålla en liten informationsfil
(README_FOLDER.txt) i varje mapp som levereras, så att hela mappen
enkelt kan kopieras över projektet.

================================================== ARBETSPRINCIPER
==================================================

-   Mobil först.
-   Touch först.
-   CCC gör det enklare.
-   Enkelhet före komplexitet.
-   Stabilitet före speciallösningar.
-   Ta bort experimentkod som inte längre tillför värde.
-   Ingen bildgenerering under CCC-arbetet om inte användaren
    uttryckligen ber om det.
-   Uppdatera README när ett nytt gemensamt arbetssätt eller
    projektbeslut ska gälla framöver.
